난이도: lvl2

난이도에 비해 어렵다. 처음에 잔돈구하는 문제 처럼 bfs로 생각했었는데 경우의 수가 너무 많아 메모리가 터짐.

그리디로 풀어야 하는데, 10의 제곱 수 단위로 층을 이동하기에 자릿수를 떠올리는 걸 기억 해두자.

2554로 예를 들면 1의 자리부터 0을 만들어 간다고 생각하면 된다. 

4는 10으로 가는거 보다 0으로 가는것이 가깝기에 2554 -> 2550을 하여 다음 자릿수를 올리지 않고 
정답에 4를 더한다. 

그 다음이 까다롭다. 255에서 5는 위로 가던 아래로 가던 거리가 같다. 즉 자릿수를 올릴 것인지 유지할 것인지는
다음 숫자가 5를 기준으로 작냐 크냐에 달렸다. 그 다음도 5이므로 조건을 next>=5이면 자리를 올리고, 미만이면 내린다고 하면, 
현재 자릿수 remainder가 5이면, if(next>=5) 이면 answer+=(10-remainder) 하고 storey에 10을 더해주어 다음 자릿수를 올려준다.
if(next<5) 이면 answer+=remainder을 하고 다음으로 넘어간다 (자릿수 변동 x) 이 과정을 storey가 0보다 클 동안 진행하면 해결이 가능하다.
