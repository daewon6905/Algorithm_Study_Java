# Tree DP (트리에서의 동적 계획법)

트리(Tree) 구조상에서 **동적 계획법(Dynamic Programming)**을 적용하여 문제를 해결하는 알고리즘 기법입니다. 일반적인 DP가 배열이나 격자 상에서 이전 상태를 참조하는 것과 달리, Tree DP는 **하위 서브트리(Subtree)의 결과를 이용해 상위 노드의 상태를 결정**하는 방식을 사용합니다.

---

## 1. 대표적인 문제 유형

1. **최소 정점 커버 (Minimum Vertex Cover)**
    * ทุก 간선의 적어도 한쪽 끝점이 선택되도록 하는 최소 정점 수 구하기 (예: 프로그래머스 *등대*)
2. **최대 독립 집합 (Maximum Independent Set)**
    * 서로 인접한 두 정점을 동시에 선택하지 않으면서 선택된 정점들의 가중치 합을 최대화하기 (예: 백준 *우수 마을*)
3. **트리의 지름 (Tree Diameter)**
    * 트리 내 두 정점 사이의 가장 먼 거리 구하기

---

## 2. 기본 동작 방식 (Bottom-Up DFS)

Tree DP는 주로 **DFS(깊이 우선 탐색) 재귀 호출**을 이용하여 구현합니다.

1. **상태 정의 (State Mapping):**  
   각 노드 $u$에 대해 필요한 상태 값을 `dp[u][state]` 형태로 정의합니다. (예: 노드를 포함하는 경우 `1`, 포함하지 않는 경우 `0`)
2. **자식 탐색 (Post-order Traversal):**  
   DFS로 자식 노드들을 먼저 방문한 후, 자식 노드의 DP 값이 모두 계산되면 부모 노드의 DP 값을 갱신합니다.
3. **점화식 적용 (Transition):**  
   자식들의 DP 결과값을 조합하여 현재 노드의 DP 값을 결정합니다.

---

## 3. 대표 점화식 (최소 정점 커버 / 최대 독립 집합)

노드 $u$와 자식 노드 $v \in \text{children}(u)$가 있을 때:

### ① 현재 노드 $u$를 선택하지 않는 경우 (`dp[u][0]`)
* $u$를 선택하지 않았으므로, 조건을 만족하기 위해 자식 $v$는 **반드시 선택**되어야 하거나(최소 정점 커버), 자식 $v$의 선택 여부 중 **최댓값**을 취할 수 있습니다(최대 독립 집합).
* **최소 정점 커버 예시:**
  $$dp[u][0] = \sum_{v \in \text{children}(u)} dp[v][1]$$

### ② 현재 노드 $u$를 선택하는 경우 (`dp[u][1]`)
* $u$를 선택했으므로, 자식 $v$는 **선택해도 되고 선택하지 않아도 됩니다.** 둘 중 더 유리한 값을 선택합니다.
* **최소 정점 커버 예시:**
  $$dp[u][1] = 1 + \sum_{v \in \text{children}(u)} \min(dp[v][0], dp[v][1])$$
