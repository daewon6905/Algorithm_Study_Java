난이도: lvl2

어렵다 왜 lvl2인지 이해가 안간다. 아마 bfs,dfs,dp,다익스트라 등 알고리즘 요소가 없고 순수 구현 문제라서 그런거 같은데, 왠만한 그래프 알고리즘 문제들 보다 어렵게 느꼈다.
충돌을 카운팅할때 3개의 로봇이 겹친다고 2번의 충돌로 카운팅하면 안되고 1번으로 해야하는 점과 구현 자체가 쉽지 않다. 해당 풀이는 최대치로 사용할 시간대 만큼의 list를 만들어두고, 동일 시간대에 로봇 별 좌표를 기록해둠.
마지막에 시간대 별로 각 좌표 값을 map의 키값으로 두고 만약 값이 1보다 크다면 충돌이 났다고 판단.
