난이도: lvl1

반복문을 돌려야할 상한선에 대해 고민하다가 못푼 문제. 최적의 풀이는 수학적으로 최대공약수와 최소공배수를 구하여 최적의 maxTime을 구할수있지만, 제한사항을 확인하면 모든 조건이 굉장히 작기 때문에, 완전탐색이 가능하고, maxTime을 구체적으로 계산하지않고 대충 큰 숫자로 두어도 답을 내는데에는 지장이 없다. 
노란불 구간인지 확인을 remain = (t-1) % c (c는 전체 주기)로 계산하는 이런 방법과 최대공약수, 최소공배수 알고리즘은 기억해둘만한듯

**수학적인 방법이 떠오르지 않더라도, 완전탐색이 가능하기에 직관적으로 큰 수를 넣어 답을 내는 마인드를 가지자**
