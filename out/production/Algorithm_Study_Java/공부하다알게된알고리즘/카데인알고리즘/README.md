카데인 알고리즘(Kadane's Algorithm)은 1차원 배열에서 연속 부분 수열의 최대 합을 $O(N)$으로 구하는 동적 계획법 기반 
그리디 알고리즘이다. 브루트포스로 모든 구간을 탐색하면 $O(N^2)$이 걸리지만, 이전 단계의 부분합 결과를 활용해 한 번의 순회만으로 최적해를 도출합니다.


1. 이전 부분 수열에 현재 원소를 붙이기: $DP[i - 1] + arr[i]$
2. 이전 누적을 버리고 현재 원소부터 새 부분 수열 시작하기: $arr[i]$ 

따라서 점화식은 다음과 같다: $$DP[i] = \max(arr[i], DP[i - 1] + arr[i])$$

여기서 기존 DP 처럼 배열을 두고 할 수도 있지만, 굳이 필요없이 변수 두 개로 가능하여 공간 복잡도 $O(1)$로 가능하다.
