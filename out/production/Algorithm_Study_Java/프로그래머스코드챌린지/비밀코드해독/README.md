난이도: lvl2

2025 프로그래머스 코드챌린지 1차 예선 문제

조합으로 모든 경우의 비밀 코드를 생성 해두고 이 조합 경우의 수를 모두 탐색하면서 입력한 정수 모음의 조건을 모두 만족하면 전체 카운팅을 한다.
중간처리를 set을 사용하여 contains로 O(1)로 탐색이 가능해 고려했으나, 이 문제에선 for문을 하나 더 돌아도 반복문이 5번으로 고정이기에 별 차이가 없는 듯하다.
값을 찾을 때, 문제에서 오름차순으로 정렬된 배열을 제시하므로 이진탐색이나 투 포인터를 고려할만하나, 이 문제 한정 더 복잡함만 불러오는 듯함. 이진탐색, 투 포인터를 활용해도 결국 전체 조합을 생성해서 다 돌아봐야 한다는 점은 동일하기 때문에, 단순하게 가는 것이 이 문제 한정 나아보임.
