기본 아이디어는 슬라이딩 윈도우인데, 조건처리, 변수 조절 등이 까다로운 문제다.
매우 어렵게 느낌. formed 변수로 문자열 t에 있는 문자가 다 포함되었는지를 판단.
formed가 문자열 t에 있는 문자의 종류 별 개수를 카운팅한 HashMap의 크기만큼 도달할때까지 right의 크기를 증가해 substring의 크기를 늘려가고, 도달하면 substring의 길이를 갱신함.
더 짧은 길이가 있을 수 있기에, left를 증가시켜 만약 left에서 하나의 문자를 제외해도 조건을 만족하면 최솟값을 갱신하고, 아니라면 formed를 감소시켜 다시 right을 증가시킨다. 이 과정을 right이 전체 s의 길이 n보다 크지 않을때까지 진행하면 됨.
